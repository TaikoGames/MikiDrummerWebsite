One-time setup: MailerLite's key isn't in GitHub yet.
  1. In MailerLite: Integrations → API → generate a token and copy it.
  2. Open GitHub's new-secret page ↗ — name MAILERLITE_API_KEY, paste the token, save.
  3. Once more: name MAILERLITE_FROM, value digest@mikidrummer.ca (mikidrummer.ca must be verified under MailerLite → Domains).
  4. Come back and press Send newsletter.
