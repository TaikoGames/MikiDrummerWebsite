Paste a GitHub token so switches save straight to the site. It's stored only in this browser — never in the page.

Easiest: a classic token with just the public_repo scope — use the button below, the scope is pre-ticked. This repo is public and owned by the TaikoGames organisation, and classic tokens work on org repos as long as you have write access.
Fine-grained tokens also work, but for an org repo they need more setup: resource owner set to TaikoGames (not your personal account), this repository selected, Contents: Read and write, and the org must allow fine-grained tokens — an owner may have to approve it. If yours 404s, that's almost always why.

Live controls

🎬 Intro video live
When ON, visitors landing on the homepage see the intro video full-screen with a close button. Turn OFF for a normal homepage. The video itself is already set in the site config — this is just the on/off.
Show for the next:
Auto: follow my live stream
Flipping the switch (or a timer) saves straight to config.json and the site updates in about a minute — no download.
With Auto on, a check runs on GitHub every 5 minutes: the moment your YouTube channel goes live the overlay turns itself on, and when the stream ends it turns itself off. Scheduled checks queue on shared runners, so allow roughly 5–15 minutes either way.
The switch above always wins. If a stream is running and the overlay hasn't come on — or it's on and you want it gone — just flip it: that holds for 12 hours and the automatic check stands down until then. Press Back to auto (or wait it out) to hand control back.
