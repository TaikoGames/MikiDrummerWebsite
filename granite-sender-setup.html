Turn on real sending

One time, about 3 minutes, from the Gmail account the pitches should come from. After this, the band's pitch page sends for real.

  1. Copy the script. It comes with a new band password made just now. Copied ✓ Band password: . Give this to the guys; the pitch page asks for it once.
  2. Open a new Google script while signed in to that Gmail: Open script.new ↗ Select everything in the editor, paste over it, and press the save icon. Name it "GRANITE pitch sender".
  3. Deploy it. Top right: Deploy → New deployment. Click the gear, choose Web app. Set Execute as: Me and Who has access: Anyone, then Deploy.
  4. Allow it. Google asks for permission to send email as you. Click Authorize access, pick your account, then Advanced → Go to GRANITE pitch sender → Allow. Google shows this warning for any script you write yourself.
  5. Send Claude the Web app URL it shows (it starts with https://script.google.com/macros/s/). That's it: the band page starts sending.
