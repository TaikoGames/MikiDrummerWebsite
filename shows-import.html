📋 Import shows

← Admin

Paste a listings page — select all on the site, copy, paste here. It pulls out the date, bands, venue, city, price and ticket link, marks anything already on the board, and lets you fix a row before it goes in. Nothing is sent anywhere until you press Add.

Undated lines are skipped rather than guessed at. A year is only assumed when the listing leaves it out, and then it is the next time that date comes round.

Add writes straight to punkbc-shows.json on GitHub with the token from the Admin page. The board re-bakes itself on the next scheduled run, or you can run the workflow to see them sooner.
