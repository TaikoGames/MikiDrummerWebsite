GRANITE Light Show

Feeds the Behringer's outputs into the artwork: each output drives its own lights on the image, live. Plug the mixer in over USB, pick it below, map outputs to zones, then hit Show mode and put it on the projector.

Show mode goes fullscreen and hides everything but the artwork — Esc or click to come back. Nothing is uploaded and no audio is played back; the page only reads levels.

Getting all the channels through: the browser decides how many it hands over, not the mixer. Use Chrome or Edge on desktop, put the interface in its multichannel USB mode (X-Air/XR18 → 18 in, X32 → 32 in) and pick the matching count above. Safari and Firefox generally cap at a stereo pair. If only 2 arrive, the page falls back to splitting the main outs into Low/Mid/High so the lights still move — the status line tells you which you got. On Windows, check the device's channel count in Sound → Recording → Properties too; Chrome won't offer more than Windows exposes.
