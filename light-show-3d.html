GRANITE Light Show 3D

An avenue of LED pillars running back to the Cosmos artwork, with sweeping beams and drifting light. The kick, snare and cymbals each drive their own part of the show, and every song in the set has its own preset. Step through the set with → / ← (a Bluetooth page-turner pedal sends these too), then hit Show mode and put it on the projector.

Nothing running. Try Demo beat to see it move with no audio.

In show mode: →/PgDn/Space next song · ←/PgUp previous · 1–9 jump to song · B blackout (between songs, talking) · T song titles on/off · Esc exit.

1 · Setlist → presets

    Saved on this device as you edit. Click a number to jump straight to that song.

    2 · Presets

    Clicking one previews it now and puts it on the current song.

    3 · Audio

    With only 2 channels the kick, snare and cymbals are split from the main mix by frequency (Low / Mid / High), which is fine for most rooms. If the mixer gives you separate channels, point each one at its own channel for much tighter hits.

    4 · Real LED strips (WLED)

    Off.

    Setup: each strip runs off a WLED controller on the same Wi-Fi as this laptop. Find each one's IP in the WLED app and type it in. Then, on this laptop, download the bridge and run python3 wled_bridge.py (Windows: py wled_bridge.py) and leave the window open. It passes the colours on, because browsers can't talk to the strips directly. Use Chrome or Edge. Side picks which row of towers a strip copies. Runs: if one strip zig-zags up and down a truss, say how many vertical runs it makes and each run becomes its own tower. Identify sends a white dot up that strip so you know which is which. If the page closes, the strips go back to their own WLED effect after 2 seconds.
